Profile

In games every frame has to finish in a few milliseconds, while physics and AI run in parallel and the same code has to work on PC and consoles. Working within those limits every day taught me to write C++ with performance and concurrency in mind, a habit that is just as useful outside games.

Concurrency

Asynchronous computations with mutex-based synchronisation and multithreaded AI workloads that run alongside the main loop.

Performance

AI and machine learning
